# TodoApp

Application de gestion de tâches (To-Do) en React + Vite + TypeScript.

## Lancer le projet

```bash
npm install
npm run dev
```

Ouvre `http://localhost:5173`.

## Build

```bash
npm run build
```

## Fonctionnalités

- Ajouter / supprimer des tâches
- Cocher une tâche comme terminée
- Filtrer : Tous / Actifs / Terminés
- Persistance dans `localStorage`

## Tests

Aucun test automatisé configuré pour l'instant.
